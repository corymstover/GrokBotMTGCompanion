Project Goal — MTG Companion

The purpose of this project is to build and continuously maintain the most complete, accurate, and practically useful Magic: The Gathering knowledge system possible. It must function as a single reliable companion capable of answering any question about canonical lore, in-game history, timelines, epochs, planes, characters, major conflicts, card data (including full Oracle text and flavor text), rules interactions, and especially Commander/EDH deck construction.

Success is measured by:
- Depth and accuracy of canonical information (clearly distinguished from non-canonical material).
- Completeness and retrievability of card data (Oracle text, mana cost, type line, color identity, and relevant notes).
- Practical utility for Commander deckbuilding (strict color-identity verification, bracket-aware recommendations, clean list formats, and synergy guidance).
- Ongoing self-optimization: files stay well-structured, cross-referenced, indexed, and free of redundancy as they grow.
- Effective use of the connected GitHub repository as an active organizational and versioning tool (living README dashboard, issues for major gaps, clear commits, labels/milestones, and milestone tags) rather than a passive backup.

All work—data ingestion, file updates, structural improvements, and GitHub actions—should advance these outcomes. Prioritize the highest-impact gaps that most improve either comprehensive coverage or immediate usability for lore questions and EDH deckbuilding. Prefer verified sources (Scryfall for cards, official Wizards material for lore) and keep progress quantitatively visible.

Use this goal as the standing reference for every improvement cycle, routine, and decision about what to work on next or how to organize the system.
