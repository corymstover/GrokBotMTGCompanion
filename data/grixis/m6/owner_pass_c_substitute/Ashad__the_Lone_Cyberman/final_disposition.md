## Material current rules determination

WotC official Comprehensive Rules PDF (https://media.wizards.com/2023/downloads/MagicCompRules20230616.pdf, 111.12; updated numbering 111.13) says copy of a PERMANENT SPELL becomes token as it resolves **but the token is not “created” for creation-trigger/replacement effects**. Doctor Who release notes confirm Ashad permanent-spell-copy outcome; Outlaws notes define Worldwalker Helm replacement on token CREATION.

- Ashad casualty copy of artifact SPELL Worldwalker Helm becomes a token Helm; NO additional Map from original Helm's if-you-would-CREATE replacement at that moment. It is still an artifact token later targetable by Helm's activated ability.
- Three Steps Ahead 3U clone mode, Artificer Class Level3 end-step token copy and Helm's own 1U,T copy ability each explicitly CREATE token artifacts, and active Helm replacement adds Map(s). A newly created Helm doesn't retroactively apply to itself, only later creation events.
- Urza can tap artifact tokens for blue; new NONCREATURE Helm tokens aren't held by creature summoning sickness. With an initial Helm token, 1U activation resources, original Helm, Urza and uninterrupted responses, successive Helm token copies yield growing Map production and can generate arbitrarily many artifact-token ETBs. A valid payoff and opponent interaction must be accounted for. It is NOT a guaranteed win from a static card list.

This rule distinction is a meaningful improvement to the evidence: careless simulation treating permanent spell-copy tokens as CREATED would overcount Maps and invalidate an apparent combo.

## Tradeoff, alternatives, opposition and decision gate

Three Steps Ahead copies controlled Helm/other artifact right NOW for 3U, possibly bootstrapping token Helm/Map and Urza loop faster; its alternative modes counter a spell or loot, and it requires no casualty fodder. But it is a NONARTIFACT instant, target-dependent and a one-shot. Artificer Class 1U permanently discounts first artifact spell EACH turn by {1}, Level2 at 1U reveals an artifact to hand, Level3 at additional 5U yields a future recurring end-step token copy. Full investment totals 10 mana spread out, while early discounts and artifact acquisition can rescue a 30-land opening and work with Shimmer Myr on opponent turns.
