## Key novel rules distinction resolved from Stage A

Ashad grants casualty2 to FIRST NONLEGENDARY ARTIFACT SPELL each turn. A copied permanent artifact spell becomes a token when its spell-copy resolves, but does not count as a SPELL CAST. Critically, WotC CR 111.12 expressly states that such a permanent spell-copy token is **NOT “created”** for triggered/replacement abilities referring to creating a token. This nuance was unresolved in sealed Stage A:

- Ashad casualty copying a cast Worldwalker Helm puts token Worldwalker Helm into play. Despite it being an artifact TOKEN, the event is NOT a token creation for Worldwalker Helm's own if-you-would-create-tokens replacement. Existing Helm therefore adds **no Map** from that spell-copy conversion alone. The resulting token Helm is a legitimate artifact TOKEN target for later Helm-copy abilities.
- Three Steps Ahead's 3U copy mode EXPRESSLY CREATES a token copy of target controlled artifact or creature. When copying an original Worldwalker Helm, any Helm replacement effect already on battlefield adds a Map. Artificer Class Level3 at end step also expressly CREATES token copy and can generate a Map. Worldwalker Helm's own 1U,T ability likewise expressly creates a copy of TARGET ARTIFACT TOKEN and generates Map(s). A newly created Helm's replacement doesn't apply to its own creation; it affects later creation events.
- Existing ETB triggers (Reckless Fireweaver, Ingenious Artillerist, etc.) can see an artifact entering from the Ashad artifact spell copy, although token-creation replacement does not apply. Jhoira/Poetic Ingenuity/Uthros cast triggers do NOT gain extra CASTS from artifact-spell copies.
- Worldwalker Helm is the actual canonical card name. WotC published rulings occasionally spell the name “Worldwaker”; this is not an unresolved card alias or canonical illegal name.

This distinction must be represented exactly in targeted effect-aware certification. Treating spell-copy token arrival as an effect CREATING a token would grant extra Maps, potentially falsely certifying an infinite token loop.

## Exact unresolved improvement: IN Three Steps Ahead / OUT Artificer Class

Three Steps Ahead costs U base plus {3} for artifact/creature token clone mode, **3U now**. Alternate spree modes: U plus {1}{U} counter target spell, U plus {2} draw two/discard one; multiple modes pay all their additions and occur in printed order. It is instant-speed, can select an existing original Helm/Urza-relevant artifact, doesn't require power2 casualty or commander, and may protect combo. It is NONARTIFACT, so cannot itself gain Ashad casualty and its copy mode needs a legal battlefield target.

Artificer Class costs 1U, provides first artifact spell each turn costing {1} generic less; Level2 costs 1U and reveals until an ARTIFACT CARD enters hand; Level3 costs 5U and grants an end-step recurring artifact token copy. Total cast+both upgrades 2+2+6=10 mana over turns, not a one-shot 10-mana requirement but slow/fragile. Importantly first-spell discount improves this low-land 30-land shell, including opponent-turn artifact casts with Shimmer Myr, and Level2 obtains a valuable artifact to hand even without ready Helm+Urza. Neither is universally dominant.

**Conditional Helm/Urza combo trace, not observed testing:** Control Urza, Lord High Artificer and an original Worldwalker Helm with enough mana to spend 3U and begin a 1U Helm activation. Cast Three Steps targeting Helm. It resolves creating token Helm plus at least one Map (from preexisting Helm replacement). The token Helm is a NONCREATURE artifact and may tap for its activated ability immediately. Its 1U,T makes copy of token Helm, a true creation event yielding new Helm plus extra Map(s) from all preexisting Helm replacements. Urza permits tapping artifact tokens for U. When enough untapped artifacts/Maps pay successive 1U and newly created noncreature Helm tokens can tap to copy further token Helms, the process scales arbitrarily in an uninterrupted game, yielding artifact ETBs and possible Reckless Fireweaver/Artillerist damage. The first activation still needs real mana; newly created Helm's replacement applies only on LATER copy events, and opponents can counter Steps or remove relevant Urza/Helm, stop activated abilities or prevent payoff. No unconditional deterministic win from card names alone.

A different route: casting Worldwalker Helm as Ashad's first eligible nonlegendary artifact spell and paying casualty can produce a token Helm WITHOUT initial Map via copy resolution. It then can be targeted by original Helm, potentially bootstrapping the true creation sequence later after available 1U. Steps may reach the line faster if the original Helm is already out and cannot be recast. Class Level3 can reach a similar copy on a future end step with 10 distributed mana, but offers earlier discount/tutor.

**Alternative cuts:** Unwinding Clock can be essential to repeated mana/Helm activations each opponent turn, particularly with Shimmer Myr. Thopter Spy Network produces only 1/1s insufficient individually for casualty2, yet its artifact bodies and combat-draw are valuable. Padeem protects Ashad/Helm as artifacts, and KCI/Twinning Staff are central. Steps replacing these is not free. No exact alternative shown superior across meta.

## Shared agreed deck identity, opportunity costs and tests

30 lands including Great Furnace, Seat of the Synod and Vault of Whispers are lands placed not artifact spells cast; Urza's Saga is enchantment land, likewise not a cast artifact. Cost reducers/rocks accelerate but many fall to artifact hate and cannot substitute for UBR in every opener. Biotransference makes creature SPELLS artifact without removing legendary status. Poetic Ingenuity's 3/1 or Biotransference 2/2 generated upon artifact CAST arrives too late to fund that same spell's casualty. Copying Portal to Phyrexia/Wurmcoil/Ichor Wellspring is profoundly on-identity but demands resources. Opponent removal before Ashad casts artifact, targeted grave hate, response to Steps/Helm and artifact wipes meaningfully lower practical reliability.
