# Abaddon Phase B — same-state hand acceleration × other hand cascades

**Preregistered before new implementation**: commit `58fa8dfd45d673daec42f67d9d248df2c7ad9cbb`. Source: locked Abaddon approved raw SHA-256 `2d6203d274c25e67fb93acf5e6784dce4ee1e8999844a6ab032d9b15995acfbf`, frozen exactly 99 physical cards. No canonical edits.

Earlier PRs independently added six physically hand-paid accelerants (PR #526) and more Abaddon-granted cascade triggers from other named hand spells (PR #530). Simply adding their rates would be wrong: a tutor/exile spell, mana added by an early cascade, and reordering the library can affect subsequent mana payments and draws. This preregistered **two-factor ablation** tests both extensions **on the same mutable state**.

## Four paired controlled arms

1. **Neither**: calls the exact unchanged PR #524 Ignus-only source-paid one-trial predecessor through PR #530's control. No six hand accelerants or additional core hand cascades.
2. **Hand ramp only**: delegates directly to PR #526's unchanged `hand_acceleration` one-trial. Lotus Petal, Sol Ring, Mana Vault, Dark Ritual, Cabal Ritual, Rite of Flame physically resolve after mana payment, but ignore their possible granted cascades.
3. **Other core hand cascades only**: delegates directly to PR #530's `plus_other_qualified_hand_casts` one-trial. Source-paid Boltwave, Flame Rift, Familiar, Birgi, Rakdos, Assault when actually hand-cast in the fixed core sequence can receive and resolve Abaddon-granted cascade, but no fast-mana hand-phase model.
4. **Both**: follows the identical sourced 99-card setup/seed but now physically hand-casts the six accelerants **and** grants all those source spells cascade whenever Abaddon is already controlled and that turn's aggregate opponent loss `X` is at least their **printed mana value**. Cascade exiles and resolves a supported first eligible hit *before the original source spell resolves*; Birgi's cast red trigger (when already controlled) happens first. Afterwards the source's actual red/black/colorless mana or artifact enters, taps, or sacrifices in exactly the same physical mana pool. The core named spell phase also permits other Abaddon cascades. Every own turn independently audits the 99-card physical inventory.

A central previously unmodeled interaction now **actually happens in the both arm**: a zero-mana-value **Lotus Petal cast from hand while Abaddon is controlled gains cascade, even if X=0**. It exiles the entire remaining library because no card has negative mana value and returns all cards to the bottom in a seeded random order. **No free spell is produced.** Only after that does Petal resolve and may be tapped/sacrificed for one red under the declared fixed choice. This models a real change to subsequent library order, not just a separate rules vignette.

The modes use five physically source-matched single-slot lists (approved, Ignus/-Rakdos, Ignus/-Nightscape Familiar, Ignus/-Rite of Flame, Assault/-Rakdos), two fixed engine-first/burn-first casting orders, and 500 identical-seed ten-turn trials for each mode/variant/policy: **20,000 bounded trajectories**. Land drops, fetches, drawn cards, spell-cost source taps, graveyard, cast triggers, actual supported cascading spell effects, and Mana Vault persistent tapping/draw-step self-damage are shared within each trial.

**Measurement constraints:** Compare per-trial occurrence of paid Ignus, Ignus cascade, other hand cascade, and at least one supported hit-resolution across all four modes. The original legacy predecessor only exports some seed-level booleans, not each exact event count, so **do not put a boolean 0/1 in an event-count column**, and report detailed event counts only in the fully joined arm.

## Still absent

This model remains a deliberately **restricted deterministic pilot**, not a real Commander multiplayer game. It still omits most of the 99-card hand casts (e.g. Wheel/Windfall, Jeska's Will, cantrips, many interaction and win-condition spells), paid hand-cast Talismans/Arcane Signet/Chrome Mox/LED, smart mulligans and optimized colored-resource conservation, complete combat and Neheb/Loyal/Assault lines, alternative tutoring priorities, game-state legality such as Rule of Law/Drannith during the randomized pilot, opponent removal and disruption, all other cascade engines and triggered rewards, and measured wins. Prior eight targeted interruption scenarios and 12-source-verified cascade hit subset remain separately tested; the above 20,000 samples assume the board survives.

**Result standard:** Only exact paid-state differences under fixed pilot assumptions, **never a full game win rate, net candidate superiority, M6 certification, or an approved card substitution**. All approved canonical 62 decks stay locked; owner's formal waiver for non-independent Pass C reviews remains respected without waiving M6.6/M6.7 evidence. Grinning Ignus remains HOLD until a genuinely decision-grade comparative analysis.
