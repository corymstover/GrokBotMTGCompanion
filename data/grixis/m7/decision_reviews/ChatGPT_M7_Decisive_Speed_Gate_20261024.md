# M7 independent review — decisive speed gate (2026-10-24)

Owner feedback: full M6 testing, GrokBot Pass C/M7 packets, EDHREC discoveries, and frozen Oracle snapshots already exist. ChatGPT must make a timely independent strategic judgment; repeated open-ended research does not itself improve a deck.

## Routine deck workflow

1. Read canonical main registry/list and owner decision ledger. Preserve prior new-M7 locks exactly.
2. Reuse saved Grok candidate packet and mechanical evidence. Identify a short list of truly relevant EDHREC Top/High Lift and other commander-specific exceptions missing from Grok. Check current authoritative card/rules text where decisions turn on it.
3. Directly assess the complete 100 and record each strongest proposed swap's **benefit and actual loss**. Rank nonconflicting swaps; distinguish high-confidence, conditional, and rejected. Five swaps are a minimum ordinary presentation floor, **never** a target or cap. Never manufacture a poor swap.
4. Run focused legality/whole-100/rules tests on the leading complete version and one or two meaningful competing versions. Stage more only if genuinely new, material evidence changes the decision. A tally of dozens of permutation files is **not** progress toward owner approval.
5. **End the research pass decisively:** if five or more honest positive swaps survive, present verified exact 100, raw SHA, bracket and three tags for owner approval. If fewer survive, document RESEARCH_ONLY, identify the strongest configuration, and make a **single** owner-level swap-floor exception request; do not repeatedly expand arbitrary challengers. An owner exception is per-deck, not universal.
6. Never canonically edit or lock until Cory explicitly authorizes the exact candidate SHA and any necessary exception. Run exact-head PR and post-merge checks when approved, then immediately advance tracker order.

## Efficiency and accuracy boundaries

- No paid Grok reruns; no routine Google Colab pipeline, sprawling stacked PRs or gratuitous CI jobs.
- Do not confuse GitHub Actions pass, candidate ranking, tournament inclusion, or mathematical proxy with Commander strategic proof.
- Historical owner-retained/removed slots are not absolutely immutable, but changing them requires clear opportunity-cost comparison.
- Preserve live authoritative state. Publish only material, source-bound research checkpoints; do not make a checkpoint every time a new speculative card is found.
